Becoming a Registered Nurse in Canada

Pathway for international RN/LPN applicants entering Canada via NNAS credential evaluation, provincial English/jurisprudence checks, and NCLEX-RN.

Open Interactive Canada Guide

Key Requirements

Qualifying Exam: NextGen NCLEX-RN + Jurisprudence Exam

Language Test: CELBAN or IELTS Academic (Writing 7.0 / Reading 6.5 / Listening 7.5 / Speaking 7.0)

Lab Unit System: SI Units (mmol/L, μmol/L, °C) · Timeline: 8–16 Months (NNAS Advisory Report -> Provincial Assessment -> NCLEX-RN)

Step-by-Step Roadmap

  1. Open an NNAS (National Nursing Assessment Service) profile selecting target province (e.g. Ontario CNO, Alberta CRNA, British Columbia BCCNM).
  2. Submit notarized ID, school curriculum forms, UNMC registration verification, and last 3–5 years nursing practice forms.
  3. Complete provincial language proficiency + jurisprudence exam once NNAS issues the Advisory Report.
  4. Complete any Supervised Practice Experience (SPEP) or bridging course if gap identified, then pass NCLEX-RN.

Document Checklist

  • NNAS Advisory Report
  • Official Employment Verification Forms (Safe Practice Hours)
  • CELBAN / IELTS / OET Results
  • Police Vulnerable Sector Check
