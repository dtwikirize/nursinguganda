Becoming a Registered Nurse in Australia

How overseas qualified Registered Nurses (Stream B IQNM) qualify in Australia using AHPRA's Outcome-Based Assessment (NCLEX-RN + Adelaide OSCE).

Open Interactive Australia Guide

Key Requirements

Qualifying Exam: Outcome-Based Assessment (OBA): NCLEX-RN MCQ + Australian Practical OSCE

Language Test: IELTS 7.0 all bands OR OET Grade B all bands OR PTE 65 all bands

Lab Unit System: SI Units (mmol/L, °C) · Timeline: 6–14 Months (IQNM Self-Check -> OBA NCLEX -> OSCE -> AHPRA Registration)

Step-by-Step Roadmap

  1. Complete AHPRA's online IQNM Self-Check to determine qualification stream (most African diplomas/degrees without substantial US/UK equivalence enter Stream B OBA).
  2. Submit identity, qualifications, and ANMAC / AHPRA portfolio verification plus English test scores (IELTS 7.0 / OET B).
  3. Pass Stage 1 OBA (NCLEX-RN multiple-choice computer exam).
  4. Pass Stage 2 OBA (Clinical OSCE assessing safe Australian clinical practice & cultural safety), then apply for AHPRA registration.

Document Checklist

  • IELTS 7.0 / OET B / PTE Academic 65 Result
  • Verified Qualification & Home Nursing Board Good Standing
  • Criminal History Check (International)
  • NCLEX-RN + AHPRA OSCE Pass Confirmation
