NURSING UGANDA — STACKED LOGO
=============================

WHAT'S INSIDE

  logo/       Icon + wordmark together
              nursing-uganda-logo-light   for white / light backgrounds
              nursing-uganda-logo-dark    for dark backgrounds
              nursing-ug-logo-light/dark  the same style reading "Nursing UG"
              .svg   use on websites (scales cleanly, text is outlined)
              .png   transparent, 1x = header size (icon 57 px), @2x for retina screens

  wordmark/   The text only, no icon. Fully vector, sharp at any size.
              .svg plus transparent .png at 1x, @2x and @4x.
              Use these with your ORIGINAL icon file for print, banners
              and anything large.

  web/        header-logo.html: ready-to-paste HTML/CSS for your site header
              (light and dark). nursing-ug-icon.png is a stand-in; swap in
              your original icon file.

  preview.png  All four logos at a glance.


IMPORTANT ABOUT THE ICON
  The NU icon in the logo/ files is taken from the screenshot you shared
  (57 x 57 px). It is unchanged, but it is low resolution, so it looks
  soft when enlarged. For anything bigger than the website header, use the
  wordmark/ files with your original icon file, or send the original icon
  and the logo files can be rebuilt sharp at every size.


COLOURS
  Ink (Nursing, light version)      #1C1D1F
  Purple (UGANDA / UG, light)       #A137F2
  Lavender (UGANDA / UG, on dark)   #B36AFA   (from the U in your icon)
  White (Nursing, dark version)     #FFFFFF


TYPE (Poppins, free on Google Fonts)
  "Nursing"   Poppins Bold 700, letter-spacing -0.02em
  "UGANDA"    Poppins SemiBold 600, 30% of the size of "Nursing",
              letters spread evenly across the full width of "Nursing"
  "UG"        Poppins SemiBold 600, letter-spacing 0.3em, followed by a
              purple line that fades out to the right


PROPORTIONS (based on the "Nursing" size, N)
  Icon height          1.425 x N   (57 px when N = 40 px)
  Icon to text gap     0.325 x N
  Gap under "Nursing"  0.175 x N
  "UGANDA" size        0.3 x N


USE IT WELL
  Clear space: keep empty space of at least half the icon's height on every
  side of the logo.
  Minimum size: icon 32 px high on screen. Below that, use the icon alone.
  Don't stretch, recolour, add shadows, or rearrange the parts.
